# 模型算力走云端路线：现阶段互联网 API，生产为专有云版本

模型层放弃自托管 GPU 路线（机场流量下算力需求约 2×8×A800，年成本为云端的 4–7 倍，且本地资源不满足）。决定：现阶段使用互联网云端 LLM API（小程序本就工作在互联网域）；生产形态选择云厂商专有云版本（逻辑不出域、VPC 内 RTT 更优）。数据出域不作为约束，PRD 开放问题 2 关闭。

## Status

accepted（2026-07-21，grilling 会话确认）

## Consequences

- 生产网架构方案 AI 算力区改写：GPU 服务器×2 删除，替换为专有云 endpoint + 专线接入。
- 延迟优化目标转为云端结构优化（流式输出、context caching、模型分层、调用压缩、就近接入），完整答复 p50 目标 5–8s。
- 单会话成本预期从 ¥0.047 降至 ¥0.015–0.025。
