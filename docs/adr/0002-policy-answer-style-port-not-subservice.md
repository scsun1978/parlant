# 政策问答改造走"口径移植"（方案甲），不做运行时子服务

针对 B 线政策类问题 deflect/澄清/误路由的短板（cross-b 实测），决定把 A 线已验证的"答案必须命中知识库原文、保留原文数字口径、附来源"约束与延误/退改/安检/行李话术模板，移植为 B 的 answer_composer 模板与 authority_routing 规则；不让 B 在运行时调用 A 作为政策子服务。

## Status
