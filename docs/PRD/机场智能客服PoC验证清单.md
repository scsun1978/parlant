# 机场智能客服 PoC 验证清单（2026-07）

**适用对象**：机场小程序智能客服 + 数字人项目的技术选型评审
**文档性质**：一页纸验证清单——每条生态线列明验证步骤、评估指标与决策门槛，供团队内部评审和实测使用

---

## 一、通用评估指标与决策门槛（所有线共用）

| 指标 | 门槛值 | 说明 |
|---|---|---|
| 意图覆盖率 | ≥ 85% | Top 50 高频意图正确路由并给出正确回答 |
| 首 token 延迟 | ≤ 1.5 s | 文字通道；语音/数字人端到端 ≤ 1.5 s（调优后 0.7–1.1 s 为良好） |
| 高合规问答 | 关键事实错误零容忍 | 退改签规则、行李限额、安检违禁品等必须命中知识库原文 |
| 一般问答幻觉率 | ≤ 2% | 抽样人工标注 |
| 工具调用成功率 | ≥ 98% | 航班查询、订单接口等函数调用链路 |
| 人工接管率 | ≤ 15% | 无法解决且未正确转人工视为失败 |
| 可审计性 | 全链路 trace 可回放 | 满足民航服务留痕与合规审计要求 |
| 单次会话成本 | ≤ ¥0.05（示例） | 按自建/商用 API 方案实测后设定 |

> 门槛数值为建议起始值，可按业务量与 SLA 调整。

---

## 二、线 0 · 模型层自托管基线

**目标**：建立模型层基准，为三条框架线提供统一推理底座。

**步骤**

1. 从 GLM 5.2 / Kimi K2.7 / DeepSeek V4 / Qwen3 中选 2 个候选模型。
2. 用 vLLM 或 SGLang 部署（8×H100 级），暴露 OpenAI 兼容 API。
3. 跑同一套评测语料（≥500 条真实/仿真问句，含 20% 长尾与对抗样本）。

**通过门槛**

- 高合规问答准确率与商用 API（如 Claude / 通义千问商用版）差距 ≤ 3 个百分点。
- 并发能力满足峰值客流换算的 QPS。

---

## 三、线 1 · 阿里生态（AgentScope + 百炼/HiMarket）

**定位**：开源框架本地部署，适合自主可控路线。

**步骤**

1. 本地部署 AgentScope（Apache 2.0，全异步、ReActAgent），接入线 0 自托管模型。
2. 复刻 5 个核心流程：航班查询、退改签引导、行李规则、安检须知、人工转接。
3. 用 Runtime 服务化 + Studio 做评测与可观测。
4. 若需平台化能力（知识库、评测、发布），再评估百炼/HiMarket 私有化方案。

**通过门槛**：对比 LangGraph 基线，开发效率与可观测性不劣（建议各 1 人同步开发同一流程做 A/B）。

---

## 四、线 2 · 腾讯生态（云 ADP + 元器）

**定位**：渠道最快，适合 MVP 快速验证。

**步骤**

1. 元器建智能体 + 知识库（先灌 50–200 条高频 FAQ）。
2. 一键发布到小程序 / 微信客服测试号，真实用户小流量灰度。
3. 云 ADP 工作流复刻同 5 个核心流程，跑内置评测。
4. 合规评审：数据驻留与审计留痕是否满足民航监管要求。

**通过门槛**：渠道接入 ≤ 3 人日；**若合规评审不通过，该线仅作 MVP 验证，不进生产候选**。

---

## 五、线 3 · 字节生态（coze-studio）

**定位**：开源可自托管，但需谨慎核对能力缺口。

**步骤**

1. Docker 部署 coze-studio，接入线 0 自托管模型。
2. 对照扣子线上版逐项核对缺失功能（多 Agent、发布管理、音色/数字人能力等）。
3. 复刻 5 个核心流程。

**通过门槛**：缺失功能不阻塞核心流程方可进入候选；线上版（纯云端）默认不满足数据驻留，仅作体验参照。

---

## 六、数字人语音附加验证（叠加在胜出线之上）

**步骤**

1. 用 Pipecat 或 TEN Framework 搭建 ASR → LLM → TTS 级联管线，接自托管模型。
2. 调优 turn detection 与 barge-in（打断）参数。

**通过门槛**

- 语音端到端延迟 ≤ 1.5 s（目标 0.7–1.1 s）。
- 用户打断成功率 ≥ 95%。

---

## 七、节奏建议（6 周）

| 周期 | 工作内容 |
|---|---|
| 第 1–2 周 | 线 0 模型基线 + 线 2 元器 MVP，先验证意图覆盖率 |
| 第 3–4 周 | 线 1 AgentScope vs LangGraph 基线 A/B 开发同一套流程 |
| 第 5–6 周 | 语音/数字人叠加验证 + 终审选型会 |

**评测语料**：≥500 条真实/仿真问句，含 20% 长尾与对抗样本（方言、错字、多意图混句、诱导性提问）。
